# Deepfall — ห้วงลึกของผู้เลือก

เกมกาชาแนววางแผนเทิร์นเบส: ถูกดึงเข้าไปในเกมที่กลายเป็นโลกจริง อัญเชิญวีรบุรุษ แล้วพาลงดันเจี้ยนที่ยิ่งลึกยิ่งยาก วีรบุรุษที่ล้มอาจตายถาวร

## เล่น / แก้เกม
- `index.html` — ตัวเกม
- `editor.html` — เครื่องมือแก้ข้อมูล (ค่าพลัง ตัวละคร สกิล ศัตรู เหตุการณ์ เนื้อเรื่อง ลองใส่ภาพ) แก้แล้วเปิดเกมในเบราว์เซอร์เดียวกันจะเห็นผลทันที
- เนื้อหาทั้งหมดอยู่ใน `data/*.json` ภาพอยู่ใน `assets/`

ต้องเปิดผ่านเว็บ (artifact, GitHub Pages หรือ `python3 -m http.server`) เพราะเกมโหลดไฟล์ข้อมูลด้วย fetch

## ส่งการแก้ไขให้ Claude
Editor → แท็บ "ส่งออก" → คัดลอกทั้งหมด → วางในแชทพร้อมบอกว่า "บันทึกลงเกม"
